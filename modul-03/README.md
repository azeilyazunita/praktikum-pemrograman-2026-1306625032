## 2. Mathematical Equation
> a. Deret McLaurin untuk Sinus:
> $$\sin x = \sum_{n=0}^{\infty} (-1)^n \frac{x^{2n+1}}{(2n+1)!}$$
> b. Deret McLaurin untuk Cosinus:
> $$\cos x = \sum_{n=0}^{\infty} (-1)^n \frac{x^{2n}}{(2n)!}$$
